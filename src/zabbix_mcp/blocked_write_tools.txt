# Tools that can change data in Zabbix and are therefore BLOCKED.
#
# One tool name per line; "#" starts a comment; wildcards work ("*_delete").
# A blocked tool is not offered to the model at all, and the same operation is
# refused when it is asked for by API method name through zabbix_raw_api_call
# or action_prepare / action_confirm ("host.delete" is blocked while
# "host_delete" is listed here).
#
# To allow a tool, DELETE ITS LINE. It can then write only to Zabbix servers
# that are not READ_ONLY (ZABBIX_MCP_ZABBIX_SERVERS__<NAME>__READ_ONLY=false).
# Keep zabbix_raw_api_call and action_prepare/action_confirm listed unless you
# really mean to let the model send arbitrary methods: they are checked against
# this list per method, but a method that has no dedicated tool is not covered.
#
# Use another file (for example a ConfigMap mount) with
#   ZABBIX_MCP_SERVER__BLOCKED_TOOLS_FILE=/path/to/file
# Print every write tool with:  python -m zabbix_mcp.write_policy
